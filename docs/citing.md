# Citing ndiffusion

If ndiffusion contributes to published work, please cite the software and the
version you used:

```bibtex
@software{whewell_ndiffusion,
  author  = {Whewell, Ben},
  title   = {ndiffusion: multigroup neutron diffusion in {C++} and {Python}},
  version = {1.0.0},
  url     = {https://github.com/bwhewe-13/NeutronDiffusion},
}
```

Releases from 1.0.0 on are archived on Zenodo, which gives each version a DOI;
the DOI will be listed here once the first release is published.
