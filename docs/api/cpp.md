# C++ API

The C++ reference is generated by Doxygen from the headers in
`cpp/include/ndiffusion/`, the solver sources and the pybind11 bindings. The
published site carries it at [cpp/](https://bwhewe-13.github.io/NeutronDiffusion/cpp/).

To build it locally:

```bash
doxygen Doxyfile                      # or: cmake --build build --target docs
```

and open `docs/doxygen/html/index.html`.

| Header | Contents |
|---|---|
| `types.hpp` | `Materials`, `DelayedNeutronData`, `BoundaryCondition`, `Geometry`, `Geometry2D`, the result structs, `UnstructuredMesh2D` |
| `solver_1d.hpp` | `KEigenSolver`, `FixedSourceSolver`, `TimeDependentSolver` |
| `solver_2d.hpp` | the structured and unstructured 2-D solvers, `validate_mesh`, `cell_centroids`, `cell_areas` |
| `solver_detail.hpp` | shared internals: input validation, boundary handling, delayed neutron algebra, the transient fission accelerator, the interrupt and warning hooks |

See {doc}`../user_guide/cpp` for building against the library.
